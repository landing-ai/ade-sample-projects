## Why this document

The collection's first **certificate of good standing**, the document lenders, landlords
and counterparties ask for to confirm an entity exists and is current with the state. It
complements `business-registration` (the filing that creates an entity) with the
certificate that attests to it years later.

What it tests:

- **Values embedded in prose.** Every value sits in a blank inside a sentence, not beside
  a label, so the model has to read the sentence to know what each one is.
- **Out-of-order text layer.** The filled-in values are written to the PDF after the
  template, so they extract at the end of the page text rather than in their sentences.
- **Near-identical dates with different meanings.** The page prints a paper-filings-through
  date (01/22/2026), an electronic-filings-through date and time (01/23/2026 @ 15:57:30),
  and the issue date and time (01/23/2026 @ 15:57:30). Only the last is the issue date.

## What it surfaced

**Reading order recovered.** Although the PDF text layer puts every filled-in value after
the template text, DPT-3 placed each value back in its sentence in the parse markdown, so
every featured field grounds to the line it appears on.

**The issue date was not confused with the filings-through dates.** The model took
01/23/2026 from the "issued this official certificate … on" sentence. The
electronic-filings-through value, which prints the same date and time, was extracted
separately and correctly.

**Grounding is line-level.** Values embedded in a sentence get a box around the whole
line, so the formation-date and issue-date crops show the full sentence around the value.
That is accurate (the value is in the box) but less tight than a labelled field would be.

**Dates ground because they are not reformatted.** The schema asks for dates exactly as
printed. Normalised to ISO, as in `business-registration`, they would read `OFF`.

**Inferred fields read OFF by design.** The booleans (`in_good_standing`, signature and
seal present, issued electronically) and `issuing_office`, which joins a two-line heading,
point at supporting text rather than containing the value. The paper-filings-through date
grounds to the sentence before its line.
