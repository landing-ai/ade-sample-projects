# Data Science Dojo 2026 — LandingAI ADE

Two hands-on tutorials built on LandingAI's Agentic Document Extraction (ADE). Each folder is
self-contained, with its own README, data and setup.

| Project | What you'll build | API key needed? |
|---|---|---|
| [Extraction_Tuning](Extraction_Tuning/) | An end-to-end extraction accuracy pipeline: Parse → Build Schema → Extract → Evaluate, refining the schema against a golden set until every field reaches ≥ 95% accuracy | Yes |
| [Verity_Citations](Verity_Citations/) | *Show Me Where It Says That*: cite, route and verify with DPT-3 Verity's word-level grounding and confidence, then find every edit between versions of a lease | No, runs from saved parses |

```bash
git clone https://github.com/landing-ai/ade-sample-projects.git
cd ade-sample-projects/Events/Data_Science_Dojo_2026/<project>
```

Then follow that project's README.
